        Setup guide

        Use this page in Chrome, in a normal tab. Do not Add to Home Screen; a home-screen copy may keep separate data, and the shortcuts open Chrome.

        Your page address

        Status of these steps: written from Apple's and Matthew Cassinelli's action documentation, not yet done on your phone. Button labels can differ slightly between iOS 17, 18 and 26. Each stage ends with a check so a wrong label is caught at once.

        Before you start

        1. iPhone on iOS 17 or later (Settings > General > About). Older versions ask for confirmation on every app open.
        2. Settings > [your name] > iCloud > iCloud Drive is on. The unlock files live in iCloud Drive > Shortcuts.
        3. Chrome is your default browser (Settings > Apps > Chrome > Default Browser App > Chrome), and you always open this page in Chrome. Don't use an Incognito tab: it keeps a separate wallet and wipes it when you close it.
        4. Open the web app address in Chrome and bookmark it.
        5. Optional, keeps Chrome tidy because every gate opens a new tab: in Chrome, Settings > Tabs > Inactive Tabs moves tabs you haven't used out of the way. Close old tabs from the tab switcher now and then.
        6. Never make an automation for Chrome, Shortcuts, Clock or Files.

        How to read the steps

        Each action shows up as a short sentence with some words in blue. A blue word is a slot: tap it to change it. Some slots arrive already filled with the result of the action above; each step says what you will see and what to change. To put a variable in a slot, tap the slot, then pick the variable from the row above the keyboard (or tap Select Variable and then tap the action whose result you want).

        Stage 1: build "OH Unlock" (12 actions)

        1. Open Shortcuts. Tap the Shortcuts tab, then + (top right).
        2. Tap the name at the top, Rename, type exactly (capital O, H, U; one space). Done.
        3. For each action below: tap the Search Actions bar at the bottom, type the action name, tap it. It is added under the one before.

        The 12 actions, in order

        1. Split Text. It reads "Split Text by New Lines". Tap Text and choose Shortcut Input; a "Receive … input" block appears at the top, leave it as it is. Tap New Lines, choose Custom, and type (the vertical bar) in the box that appears.
        2. Get Item from List. It reads "Get First Item from Split Text". Leave it as it is.
        3. Set Variable. It reads "Set variable Variable Name to Item from List". Tap Variable Name and type . Leave Item from List.
        4. Get Item from List. The list slot will probably not say Split Text. Tap it and pick Split Text, the result of action 1, not Item from List. Then tap First Item, choose Item At Index, and type 2 in the box that appears.
        5. Set Variable. Tap Variable Name and type . Leave the second slot: it already holds the Item from List of action 4, the one directly above. Two results are called Item from List; if you ever have to re-pick it, use Select Variable and tap action 4.
        6. Get Item from List. Again tap the list slot and pick Split Text, not Item from List. Tap First Item and choose Last Item.
        7. Set Variable. Tap Variable Name and type . Leave the second slot: it holds the Item from List of action 6.
        8. Adjust Date. It reads roughly "Add 0 seconds to Date"; the date slot may already show another variable. Tap the number and pick the variable Minutes. Tap the unit and choose minutes. Tap the date slot and pick Current Date.
        9. Format Date. Its date slot should say Adjusted Date; if not, tap it and pick Adjusted Date. Tap the date format (it may say Medium or Short) and choose ISO 8601. Then tap the small arrow (or Show More) and turn Include ISO 8601 Time on.
        10. Save File. It reads "Save Formatted Date to …"; if the first slot is not Formatted Date, tap it and pick Formatted Date. Tap the arrow to expand: Ask Where to Save off; the folder must be Shortcuts; Subpath = then the variable App then ; Overwrite If File Exists on.
        11. Start Timer. It reads "Start timer for 30 minutes" (the number may differ). Tap the number and pick the variable Minutes. Leave the unit on minutes. Optional: this is the "time's up" alarm. Leave it out if you don't want it.
        12. Open URLs. Tap its slot and pick the variable Link, not Item from List and not Shortcut Input.
        1. Tap Done.

        1. Shortcuts > +. Rename to .

        The 5 actions, in order

        1. Get File from Folder (called Get File on older iOS). If its folder slot is not Shortcuts, tap it and choose Shortcuts. Tap the file path slot and type , then pick the variable Shortcut Input, then type . Tap the arrow to expand: Error If Not Found off.

        Check 3. Before making any automation, run OH Gate once by hand: in the Shortcuts list, tap OH Gate. If it asks for text, leave it empty and tap Done. Answer every prompt (access to a file, opening a link) with Always Allow. Pass: Chrome opens this page with the notice "That link did not name an app." That is expected here, because nothing told OH Gate which app it was. If Safari opens instead, see Troubleshooting. Doing it now means the prompts appear in front of you, not hidden while an app is opening.

        Stage 3: one automation per app (2 actions each)

        Repeat these steps once for each app you want to budget, each with its own id.

        Check 4 (the whole loop). Open Instagram from the Home Screen.

        • Chrome should open on the gate showing "Instagram" and your balance. (This is also the "no unlock file yet" case.)
        • Tap 5 min. Chrome may ask to open Shortcuts: tap Open. Allow any other prompts. Instagram opens and stays open. A 5-minute timer is running.
        • Go to the Home Screen and open Instagram again: it opens straight away.
        • After the timer rings, leave Instagram and open it again: the gate is back and the balance shows 55.

        If an app does not open by itself after you spend, go to Settings in this web app, clear that app's open link, and from then on you will see "unlocked, open it from your Home Screen."

        Stage 4 (recommended backstop): Apple's own limit

        Settings > Screen Time > App Limits > Add Limit, pick the same apps, set the same daily time. This is the only free thing that truly blocks. Details are in Honest limits.

        This is a speed bump, not a lock.

        It works because it makes you stop and choose, every time. It does not make cheating impossible, and it would be dishonest to pretend otherwise. Here is exactly how you can get around it, so you know what you are relying on:

        • You can switch it off. Delete or pause the automation in the Shortcuts app and the gate is gone.
        • Minutes are counted when you buy them, not while you scroll. Buy 10 and leave after 2, and 10 are still spent. That is on purpose.
        • Nothing closes the app when time is up. The timer rings; the app stays open. The gate only comes back the next time you open or return to the app.
        • While an app is unlocked, it is unlocked however you open it, including from search or a notification.
        • The wallet lives in Chrome on this phone. Chrome's Clear Browsing Data (cookies and site data) wipes the balance and the history, and an Incognito tab starts with an empty wallet. iPhone browsers can also clear it by themselves if you do not visit this page for about a week. Copy a backup from Settings now and then.
        • Every gate opens a new Chrome tab. Close old ones now and then, or turn on Chrome's inactive-tabs setting.
        • You can edit your own rules. Raising the daily budget only starts tomorrow once you have spent today, but passes, caps and the app list can be changed at any time.
        • The DM pass is just three free minutes in the real Instagram. No web page can hide the feed inside Instagram's own app. The paid app does this with a private in-app view; this free version cannot.
        • A few edge cases. If you travel to another time zone, "today" follows the phone's clock, so that day's budget can cover a few hours more or less. Tapping Open again while an app is unlocked starts another timer and can stretch the unlock by up to a minute. If iCloud Drive is off, the unlock files may not save.

        Want a real lock behind it? Use Apple's built-in limit as the backstop: Settings > Screen Time > App Limits > Add Limit, choose the same apps, set the same daily time, and have someone you trust set the Screen Time passcode. That is the only free option where the iPhone itself blocks the app. Paid apps such as one hour or Opal use an Apple permission that is not available without a paid developer account, which is why this one cannot do it.
